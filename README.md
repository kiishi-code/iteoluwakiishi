# Yusuf Iteoluwakiishi — Portfolio

A responsive React + Vite portfolio for a web designer and developer based in Abeokuta, Nigeria.

## Included
- Responsive portfolio with dark/light theme toggle
- Selected project cards linking to NOVA AI, GALAXY and StudyMate
- Services, skills, process, contact details and floating WhatsApp link
- CV page at `/yusuf-iteoluwakiishi-cv.html`
- Contact form frontend and AppDeploy backend handler
- Basic deployment and test notes

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Build
Run `npm run build`. The generated static frontend will be in `dist/`.

## Contact form note
The included backend handler uses the AppDeploy SDK (`@appdeploy/sdk`) and is intended for deployment on AppDeploy. In a local preview without that backend, the contact form displays a message directing visitors to email or WhatsApp. To make submissions persist locally or on another host, implement an equivalent API endpoint and database connection.
